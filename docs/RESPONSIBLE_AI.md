# Responsible AI Use

CarbonLens calculates a vegetation-health indicator from structured satellite-derived measurements. It is not a measurement of carbon sequestration, credit quality, legal ownership, additionality, permanence, or project eligibility.

Scores can be affected by cloud cover, seasonality, sensor availability, spatial resolution, biome differences, land-management practices, and incomplete historical observations. Cached data may be older than live data. These limitations can introduce bias or error across regions and project types.

Every result requires human review before any real-world decision. CarbonLens is not a replacement for a field audit, accredited verification, legal review, or community consultation.

If enabled, an LLM may explain only structured numeric results using a sanitized, length-limited project name. It does not receive raw polygon geometry or other raw user text. Its output is length-capped, treated as untrusted text, and never determines a score or minting decision. The product remains functional when LLM features are disabled.
